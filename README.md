# 📸 Photography Sidebar Page

A simple photography-themed webpage built using **HTML and CSS**. This project demonstrates a sidebar navigation menu with a toggle button, smooth transitions, and a visually appealing background image.

The sidebar includes navigation links, social media icons, and a clean UI layout designed to practice CSS styling and positioning.

---

## 🚀 Features

* Sidebar navigation menu
* Toggle menu using CSS checkbox technique
* Smooth hover and transition effects
* Social media icons integration
* Full-screen background image
* Clean and minimal UI design

---

## 🛠 Technologies Used

* HTML
* CSS
* Google Fonts (Poppins)
* Font Awesome Icons
